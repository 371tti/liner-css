Complex Layout Patterns

Combine grid tracks, named areas, and flexible containers to arrange page regions. These classes control placement and spacing; the existing component styles provide the visual appearance. Layout containers have vertical margins controlled by --layout-group-margin-block, which scales down at both responsive steps.

Twelve-column composition

Use .col-span-* on direct children of .grid-12. At tablet and mobile widths, spans default to full width; add .tablet-col-span-* or .mobile-col-span-* to choose a smaller span on that step.

Flexible groups

.layout-stack creates a vertical group, .layout-cluster wraps items and aligns them, and .layout-switcher wraps children as space runs out. .layout-split gives the first column twice the space of the second. Use .layout-container or .layout-container-wide to center content within the configured width.

Width and Height

Use percentage utilities for proportional sizes. Percentage heights need a parent with an explicit height. .max-w-content, .max-w-wide, and the content containers use their width variables while reserving --content-width-min-margin. At mobile width, that margin uses --content-width-min-margin-mobile.

Margin and Padding

Spacing values use --frame-padding: 1 is one frame padding and 2 is twice that value. Margin, padding, and default grid/flex gaps scale down at both responsive steps.

.p-2
.p-1

Use .m-0, .m-1, .m-2, .m-auto, .mx-auto, and .my-auto for margins.

Use .px-1, .px-2, .py-1, and .py-2 for axis-specific padding.

Responsive Utilities

There are two responsive steps: tablet-* applies above 36em through 48em, and mobile-* applies at 36em and below. Wider screens use the base class.

Grid columns by breakpoint

Combine the base grid with breakpoint classes to choose the columns at each width: grid-4 tablet-grid-3 mobile-grid-2.

Other responsive modifiers

Use tablet-flex-column or mobile-flex-column to change flex direction at a responsive step; use tablet-h-auto and mobile-h-auto to reset height. Responsive width, height, gap, alignment, and grid span classes are also available. For .grid-12, use spans from 1 to 8 at tablet width and 1 to 4 on mobile, or use *-col-span-full to fill the row.
